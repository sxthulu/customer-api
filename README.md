A REST API built with Java, Spring Boot, Spring Data JPA, and PostgreSQL for managing customers.

Features
Create customers
Get all customers
Get customer by ID
Update customers
Delete customers
Endpoints
GET    /customers
GET    /customers/{id}
POST   /customers
PUT    /customers/{id}
DELETE /customers/{id}
Tech Stack
Java
Spring Boot
PostgreSQL
Maven
Postman
Run

Start PostgreSQL, then run the Spring Boot application.

API:

http://localhost:8080
